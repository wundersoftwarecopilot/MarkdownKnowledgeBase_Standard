# ADR-003: Deliver daily reports as CSV instead of PDF

## Context
ADR-002 chose PDF reports rendered with headless Chromium and sent by e-mail.
Q-001 asked whether the Beta Haulage SFTP server requires key or password authentication; the answer (2026-09-10 marta) added that their ERP imports CSV only, so PDF is not needed.
Beta Haulage is the largest customer and the reason for SFTP delivery (TASK-004).
Chromium is the largest dependency on the weighbridge PC and the slowest step of the report job.
The other customers file or print the report; none of them needs PDF specifically.

## Problem
In which format do customers receive the daily delivery report, now that the largest customer can import only CSV?

## Decision
Every customer receives the daily delivery report as one CSV file per report day, built by `src/tarelog/reports/`.
The file is UTF-8 without BOM, comma-separated, with a header row and the column order recorded in INT-HAULER-SFTP.
Beta Haulage receives it on its SFTP server (TASK-004); the other customers receive the same file as an e-mail attachment.
No PDF is produced; headless Chromium and the PDF templates are removed (TASK-007).
This replaces all of ADR-002; what stays is that the report job starts at 05:00 and delivers one report per customer and report day before 06:00.

## Alternatives considered
- Keep PDF for everyone and add CSV for Beta Haulage: two renderers to maintain, and Chromium stays on the weighbridge PC.
- XLSX for everyone: no customer asked for it, it adds a dependency, and the Beta Haulage ERP imports CSV.
- Keep PDF only: the Beta Haulage ERP cannot import it (Q-001).

## Consequences
- The CSV column order becomes an external contract: changing it needs Beta Haulage's agreement (INT-HAULER-SFTP).
- Customers who printed the PDF open the CSV in a spreadsheet instead; marta tells each of them before the switch.
- The report job gets faster and the weighbridge PC loses its largest dependency.
- Follow-up tasks: TASK-004 (SFTP delivery of the CSV), TASK-007 (remove the Chromium PDF pipeline).
