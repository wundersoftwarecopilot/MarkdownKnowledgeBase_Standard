# Q-002: Should a report day end at quarry-local midnight or at midnight in each customer's time zone?

## Context
TASK-005 gives each customer a report time zone but does not say where that customer's report day ends.
Today every report covers 00:00 to 24:00 quarry-local time (MODULE-REPORTS).
For a customer one hour ahead of the quarry, tickets weighed between 23:00 and 24:00 quarry-local time already belong to the next day.
The answer decides whether TASK-005 moves the report day or only converts the times in the file; TASK-005 is blocked until then.
The contract with Beta Haulage fixes only the 06:00 deadline, not the day boundary.

## Options
- A: Quarry-local midnight for every customer; the customer's time zone only converts the times printed in the file.
- B: Midnight in each customer's time zone; each customer's file holds exactly the calendar day its ERP counts, and the 05:00 run still covers customers up to four hours behind the quarry. (recommended)
